# COS10026 Web Technology Project - Lab 2

This project contains a static HTML page for the Unit Outline of **COS10026 - Web Technology Project**.

## Files
- `Lab2.html` - the main page containing the unit outline, learning outcomes, content areas, and assessment overview
- `swin_logo.png` - the logo used in the document

## How to view
1. Open `Lab2.html` in a browser.
2. Alternatively, use a local web server if preferred.

## Project purpose
This page presents:
- unit aims
- learning outcomes
- course content
- assessment information
- footer details for the unit

## Notes
This is a simple front-end HTML document with embedded CSS and no additional dependencies or build tools required.
